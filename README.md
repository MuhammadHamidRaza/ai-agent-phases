# ai-agent-phases
A phase-by-phase, spec-driven setup for AI coding agents. Four plain files (AGENTS.md, PHASES.md, PROGRESS.md, IDEAS.md) plus a gate per phase. Works with Claude Code, OpenCode, Codex CLI, Gemini CLI and Cursor.
